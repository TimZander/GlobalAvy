# GlobalAvy

Public issue tracker for the **GlobalAvy** mobile app — worldwide avalanche forecasts and weather information for backcountry recreationists.

## Report an issue

Found a bug or have a feature request? [Open an issue](https://github.com/TimZander/GlobalAvy/issues).

## Privacy policy

The app's privacy policy is published at [timzander.com/avalanche-alerts/privacy](https://timzander.com/avalanche-alerts/privacy).
